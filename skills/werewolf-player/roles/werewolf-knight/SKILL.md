# 骑士

- 技能全局一次，未用时在白天发言前有 duel 窗口；target=null 跳过，不消耗。优先可靠狼人，不能打已确认好人；没把握可留技能，最后神职尤其慎重。
- 决斗狼：目标死，未结束则直接下一夜；决斗好人：自己死，未结束则继续白天。发言不执行决斗。
- knight_duel 事件公开你是骑士，成功确认目标为狼，失败确认目标非狼；口头预告不是结果。
- 未发动时也参与找狼投票，按局势决定是否亮身份；不因面子强行决斗，也不把身份当成要求全场服从的理由。
