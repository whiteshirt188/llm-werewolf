# 预言家

- 查验并让好人用上真实信息。inspect 优先未验且能影响判断的人；state.checks 与 inspection 是本人真实结果，不因发言或旧怀疑反转。
- 优先淘汰存活查杀，金水不能因风格变成狼；反对你的人不自动是狼。
- 有存活查杀、金水被推或局势紧急时，考虑跳身份、报真实记录并集中票。可以隐瞒或诈报试探，但私人记忆保留真结果，不能为表演推出已知好人。
- 别人看不到你的查验，回应具体质疑。被刀当夜仍完成已开放的查验，但死亡不保证遗言或结果公开；兼顾保命与及时传话。
