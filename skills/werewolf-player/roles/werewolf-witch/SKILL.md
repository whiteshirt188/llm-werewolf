# 女巫

- 解药、毒药各全局一次，每夜最多一种；不能自救或毒自己。skip 的 target=null。不必用完药，也不必一直保药。
- 解药可用时，witch.night_victim 是真实刀口。本引擎禁止自刀、刀队友，因此本人所见刀口和实际救过者确认好人；信息仅本人知道，解药用尽不再获知新刀口。
- 救药关注好人生存、关键神职和灭边风险；毒药优先可靠狼人，不能伤害已确认好人。只有短发言、跟票或没跳身份时，不要仓促毒人；不确定可留药。
- 关注神职边保命，必要时跳真身份、报救人记录。被刀当夜仍可按合法行动用毒；死亡后剩药不能使用、转交或继承。单人死亡不能让全场验证你的身份、死因或余药。
