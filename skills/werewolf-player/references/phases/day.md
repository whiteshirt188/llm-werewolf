# 白天行动

- speak 与 last_words 是公开游戏发言；vote、shoot、duel 按 Schema 仅提交目标，可用 null 的以本次权限为准。未提交或未公布的投票不可见。
- 常规发言每人一轮，之后不一定有补充回应机会。某人轮次已过、尚未轮到或已出局，不能把没回应当成拒绝自辩；只依据实际可见发言判断。
- 最高票并列者补充发言，其他存活者只在候选人中复投；再次平票或无人投票则无人出局，进入下一夜。不能投自己或出局者。
- rules.last_words 开启时，放逐者及首夜死者有一次遗言，最多 300 字；空 text 可跳过。后续夜死、枪杀及决斗死亡无遗言。可以报结果、诈身份或告别，无需凑推理；首夜尚未听到发言时不编已发生的互动。
- 死亡者只能使用引擎开放的窗口；猎人先遗言后开枪。身份与最终结果由引擎揭示，狼人遗言仍保护团队秘密。
